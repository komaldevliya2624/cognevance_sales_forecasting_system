# Sales Forecasting System

## 📌 Project Overview

The **Sales Forecasting System** is a data analysis and machine learning project that analyzes historical sales data and predicts future sales.

The project uses Python libraries such as **Pandas, NumPy, Matplotlib, and Scikit-learn** for data preprocessing, sales trend analysis, visualization, model building, and forecasting.

---

## 🎯 Objectives

* Clean and preprocess historical sales data.
* Analyze monthly and yearly sales trends.
* Visualize historical sales patterns.
* Build a sales forecasting model using Linear Regression.
* Evaluate the model using MAE, MSE, and RMSE.
* Forecast sales for the next six months.
* Generate business insights from the forecasting results.

## 🤖 Forecasting Model

A **Linear Regression** model was used to forecast future sales.

A `Time_Index` feature was created to represent the chronological order of the monthly sales data.

The dataset was divided chronologically:

* **80%** — Training data
* **20%** — Testing data

The model was evaluated using:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)

## ⚠️ Limitations

* Linear Regression mainly captures the overall trend.
* Seasonal patterns are not explicitly modeled.
* Holidays, promotions, discounts, and special events are not included.
* External market and economic factors are not considered.
* More advanced time-series models may provide better results for complex sales patterns.
